# Central Hills SC Management App

## Run the app
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. The app runs locally in the browser. No installation or internet connection is required for this prototype.

## Included modules
Dashboard, player registration and editing, uniform catalogue and orders, payment recording, membership fees, attendance, matches, equipment, announcements, CSV exports and printing.

## Important prototype limitations
- Records are stored in the browser's local storage on the device used. They are not synchronised between phones or computers.
- Clear browser data or changing browser/device can remove access to the records. Export CSV backups regularly.
- This prototype does not yet include real user accounts, server-side permissions, cloud database, automated Mobile Money verification, SMS/WhatsApp delivery, or multi-user access.
- Do not enter sensitive real children's information until secure server-side authentication, access controls, backups and privacy safeguards are implemented.

## Recommended production upgrade
Use Next.js, PostgreSQL (or Supabase PostgreSQL), secure authentication, role-based access, server-side validation, audit logs and verified payment-gateway webhooks.
